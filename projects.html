Scam & Phishing Detector

Live

Problem — Text-based scams and phishing links are easy to miss, and most detection tools aren't tuned for how scam messages actually read.

Solution — A text classifier for scam messages, paired with a separate URL/phishing classifier so both the message and the link can be checked.

Built with — TF-IDF + Logistic Regression for text classification, trained on a custom 5,000-row dataset for Indian-context scam messages, reaching 96% recall on spam. A Random Forest model handles URL/phishing detection using PhiUSIIL features.
